# User Journey

## Tujuan

Menjelaskan perjalanan user dari blueprint strategi menjadi rencana konten dan draft konten harian yang siap diproduksi.

## Core Journey

1. User menyelesaikan strategi di Alco Creative System.
2. User membuka Alco Content Engine.
3. User mengimpor blueprint strategi lewat JSON atau paste blueprint.
4. Sistem mengekstrak data inti yang relevan untuk perencanaan konten.
5. User memilih channel utama: Instagram dan/atau Facebook.
6. User memilih horizon konten: 7 hari, 14 hari, atau 30 hari.
7. Sistem menghasilkan kalender konten dengan pembagian TOFU, MOFU, dan BOFU.
8. User memahami tujuan setiap item konten dan alasan funnel-nya.
9. User membuka salah satu hari untuk melihat brief konten harian.
10. Sistem menghasilkan caption, prompt visual, prompt carousel, atau prompt video.
11. User mengedit output bila diperlukan.
12. User menyimpan hasil sebagai draft produksi konten.

## User Goal

User ingin tahu:

- konten apa yang harus dibuat
- konten itu untuk tujuan apa
- konten itu masuk TOFU, MOFU, atau BOFU
- bagaimana membuat versi image, carousel, atau video dari ide tersebut

## Main Pain Points Solved

- Bingung harus posting apa setiap hari
- Konten tidak nyambung dengan strategi awal
- Sulit menjaga alur funnel dari awareness ke conversion
- Brief untuk desainer atau editor video tidak jelas
- Caption dan ide visual sering terasa generik

## Success Experience

User merasa sistem berhasil bila:

- kalender kontennya langsung usable
- tiap hari ada tujuan yang jelas
- output AI tidak bertentangan dengan positioning dan offer
- pembuatan konten terasa lebih cepat dan terarah
